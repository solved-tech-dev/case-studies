## 1. 算例规模与共性参数

- 模型：**Norne N64**（原始 `46×112×22` 网格经 4×4×4 全局加密至 `184×448×88`，共 `7,254,016` 逻辑单元、`2,843,196` 活跃单元）。
- 主系统：`FP64` `BSR3`（`2,843,196` 块行、`8,529,588` 未知量、储层矩阵 `19,947,562` 非零块）。
- 压力系统（CPRW）：`2,843,232` 行（含 36 个井压力方程）、`20,012,068` CSR 非零元。
- 测试硬件：
  - CPU 对照节点：双路 Intel Xeon CPU Max 9462（64 核）。
  - GPU 节点：单张 NVIDIA GeForce RTX 5090（约 32 GiB 显存，主机 CPU AMD Ryzen 7 9800X3D，驱动 `610.57.04`）。

## 4. CPR 双后端路线（XianzhiKrylov 外层/GMRES/块 ILU(0) + LinglongAMG V-cycle）

### 4.1 首日同节点无输出配对计时（Slurm 作业 `356802`，1 时间步、3 Newton、3 个线性系统）

对比双方均在同一个 RTX 5090 节点（Ryzen 7 9800X3D，1 MPI × 1 线程，绑定同一 CPU 掩码 `0x1`）顺序运行，关闭所有模拟结果文件写入：

| 指标 | CPU CPRW (`hypre` host) | GPU CPR (`XianzhiKrylov + LinglongAMG`) | CPU / GPU 比值 |

| 无模拟文件端到端 (s) | 99.09 | **83.39** | 1.19× |
| OPM 线性阶段总计（含准备, s） | 19.10 | **3.67** | 5.20× |

| 纯外层求解（含 CPRW 内层, s） | 7.656 | **0.910** | 8.42× |

GPU CPR 嵌套分阶段累计耗时（3 个线性系统之和）：
- 压力系统构建（含 True-IMPES 权重）：`1.256 s`
- 矩阵与压力向量打包（`pack_s`）：`0.583 s`
- 设备拓扑与句柄初始化（`topology_s`）：`0.225 s`；数值上传（`values_h2d_s`）：`0.225 s`；井准备：`0.012 s`
- 压力 LinglongAMG setup：`0.287 s`；细层块 ILU(0) 分解：`0.099 s`
- 压力 XianzhiKrylov GMRES：`0.715 s`（其中嵌套 LinglongAMG 单 V-cycle API 含状态查询：`0.657 s`，共 56 次调用）
- 细层块 ILU(0) 应用：`0.152 s`；储层 `BSR3` SpMV：`0.032 s`；GPU 井算子：`0.0027 s`

独立验算结果：
- 含井 GPU 算子相对误差：`8.9581e-17`
