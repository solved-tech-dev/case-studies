# 实测结果与作业记录 (RESULTS)

> [!NOTE]
> 本文汇总的所有运行数据均严格核对自实机 Slurm 作业日志与输出记录。两条路线的算法边界、矩阵形式、计时口径和硬件配置不同，**各节数据独立核对各自口径，禁止跨路线直接合并计算加速比**。

## 1. 算例规模与共性参数

- 模型：**Norne N64**（原始 `46×112×22` 网格经 4×4×4 全局加密至 `184×448×88`，共 `7,254,016` 逻辑单元、`2,843,196` 活跃单元）。
- 主系统：
  - 独立储层矩阵（不含显式井 Schur 填充）：`FP64` `BSR3`，`2,843,196` 块行、`19,947,562` 非零块。
  - 显式井全耦合主系统（`--matrix-add-well-contributions=true`）：`FP64` `BSR3`，`2,843,196` 块行、`8,529,588` 标量未知量、`55,065,494` 非零块。
  - 压力系统（LinglongAMG 混合 CPRW）：`2,843,232` 行（含 36 个井压力方程）、`20,012,068` CSR 非零元。
- 测试硬件：
  - CPU 对照节点：双路 Intel Xeon CPU Max 9462（64 核）。
  - GPU 节点：单张 NVIDIA GeForce RTX 5090（约 32 GiB 显存，主机 CPU AMD Ryzen 7 9800X3D，驱动 `610.57.04`）。

## 2. 公开 XianzhiKrylov 26.48 发行包兼容性实测（RTX 5090）

在 `gpu5090` 分区（`high` QoS，RTX 5090）使用官网发布的 XianzhiKrylov `26.48` 发行包（`libXianzhiKrylov.so.26.48.0`，SHA-256 `8661b5e5...`）执行了对照实测：

1. **旧内部接口验证（Slurm 作业 `366967`）**：
   - `26.48` 发行包本身在 RTX 5090 上通过 `15_bicgstab_ilu0` 示例（exit 0，7 步收敛，相对残差 `5.388878e-10`）。
   - 该包仅提供 `XianzhiKrylovAPI.h` 与 `XianzhiKrylovData.h`，未导出 `xk_internal_cprw_*` 符号（数量为 `0`），无法编译/链接依赖单独 `apply` 的旧接口（已据此移除 `cpr` 路线并将 `xianzhikrylov` 切换为公开 API 显式全耦合路线）。
2. **公开 API 组件烟雾测试 `check-xianzhikrylov-bsr3`（Slurm 作业 `367086` / `367095`）**：
   - 使用公开 `XianzhiKrylovAPI.h` 与 `examples/configs/xk-bsr3-bicgstab-ilu0.json` 编译运行通过，输出 `XIANZHIKRYLOV_BSR3_SMOKE_PASS`。
   - 两次数值准备+求解独立真实相对 L2 残差：`rel1 = 1.401437e-16`、`rel2 = 1.616844e-16`；`/proc/self/maps` 确认未加载 `liblinglongamg`。

## 3. XianzhiKrylov 路线（公开 API `BSR3` 显式全耦合 `--matrix-add-well-contributions=true`）

### 3.1 Norne N64 首日实测（Slurm 作业 `367087` / `367095`，RTX 5090，`--no-output`）

使用本仓库 `scripts/run-case.sh --route=xianzhikrylov --no-output --profile --true-residual` 与 `libXianzhiKrylov.so.26.48.0` 实测（`rows=2,843,196`, `blocks=55,065,494`）：

- **作业 `367087`（`max_iterations=200`）**：
  - `XIANZHIKRYLOV_PHASE_ANALYSIS` 耗时：`0.7157 s`。
  - 每次 `XIANZHIKRYLOV_PHASE_NUMERIC_PREPARE`（`BSR3` 原生精确块 ILU(0) `level=0`，5,506 万块含井 Schur 填充矩阵）：打包 `pack_s ≈ 0.193 s`、H2D 上传 `values_h2d_s ≈ 0.170 s`、ILU 数值分解 `numeric_s ≈ 70.78 s`。
  - 初始 1.0 天步前 4 次 Newton 迭代分别以 `14, 1, 45, 2` 次 BiCGStab 迭代收敛；第 5 次达 200 步上限（`rel=0.025200`）触发缩步至 `0.33` 天并完成时间步 0（3 次 Newton、37 次线性迭代）；在时间步 1 推进至进程 `1050 s` 超时上限（退出码 `124`）。
- **作业 `367095`（`max_iterations=400`，`examples/configs/xk-bsr3-bicgstab-ilu0.json`）**：
  - `XIANZHIKRYLOV_PHASE_ANALYSIS` 耗时：`0.7078 s`。
  - 前 4 次迭代收敛，第 5 次达 400 步（`83.03 s`, `rel=0.010644`）缩步至 `0.33` 天；时间步 0 完整收敛（3 次 Newton，37 次线性迭代，`14, 1, 22` 步，独立真相对残差依次为 `0.002393`、`0.004623`、`0.004724`）。
  - 时间步 1（`0.67` 天）前两次 Newton（`31, 2` 步，独立真相对残差 `0.004943`、`0.004133`）全部收敛且 `OPM_SOLVED_TECH_TRUE_RESIDUAL` 与 SDK 报告值一致；于第 11 次线性系统准备阶段达到 `1050 s` 上限（退出码 `124`）。
  - **已核对结论**：公开 `26.48` 发行包的显式全耦合路线在 OPM 2026.04 + RTX 5090 上零报错可跑通且数值残差完全一致；性能瓶颈位于含显式井稠密填充的 `55,065,494` 块 `BSR3` 块 ILU(0) 数值分解（单次 `~70.8 s`）。单独 `apply` + 独立井算子分离方案将在 `26.49` 开放对应公开接口后重新接入。
