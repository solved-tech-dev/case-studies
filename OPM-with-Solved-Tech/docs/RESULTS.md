# 基准性能结果 (RESULTS)

> [!NOTE]
> 本文汇总 Norne 4×4×4 加细网格基准测试数据。`LinglongAMG`（CPRW 压力子系统）与 `XianzhiKrylov`（显式含井全耦合系统）采用不同的数学模型、矩阵格式与计时阶段，两条路线均在同一张 **NVIDIA GeForce RTX 5090 (32 GB)** 上分别与同口径主流 GPU 求解器（AMGX / Ginkgo）对照测试。

---

## 1. 模型规模与硬件环境

- **模型**：Norne N64（`46×112×22` 全局 4×4×4 加密至 `184×448×88`，`7,254,016` 逻辑单元、`2,843,196` 活跃单元）
- **线性系统规模**：
  - CPRW 压力子系统（`linglongamg`）：`2,843,232` 标量行（含 36 个井压力方程）、`20,012,068` CSR 非零元
  - 显式含井全耦合主系统（`xianzhikrylov`，`--matrix-add-well-contributions=true`）：`FP64` `BSR3`，`2,843,196` 块行（`8,529,588` 标量阶数）、`55,065,494` 非零块（等价 `495,589,446` 标量 CSR 非零元）
- **GPU 测试平台**：单张 NVIDIA GeForce RTX 5090（32 GB 显存）

---

## 2. LinglongAMG 压力子系统求解对比（Norne 176 天，GMRES + AMG）

基于 OPM Flow CPRW 预条件器的压力子系统求解阶段，累计统计 Norne 0–176 物理天全部压力求解调用的 Setup 与 Solve 耗时（纯 GPU 压力 API 口径）：

| 求解器 | Setup (s) | Solve (s) | 压力求解累计 (s) | 压力调用 / GMRES 迭代次数 | 相对 AMGX 加速比 |
| --- | ---: | ---: | ---: | ---: | ---: |
| **NVIDIA AMGX `2.5.0`** | `33.09` | `30.38` | `63.46` | `675 / 5,043` | `1.00×` |
| **LinglongAMG `26.46`** | `6.05` | `27.67` | **`33.73`** | `669 / 5,611` | **`1.88×`** |

---

## 3. XianzhiKrylov 全耦合求解对比（Norne 首日第 1 步，BiCGStab + ILU(0)）

基于 OPM Flow 显式含井全耦合组装口径（`8,529,588` 阶、`55,065,494` 个 BSR3 块 / `495,589,446` 标量非零元，相对残差容差 `tol = 5e-3`，零初始解，独立复算主机端 FP80 真实相对 L2 残差），在同一张 RTX 5090 上以交替配对轮次测量首日第 1 个 Newton 步的完整线性求解耗时：

| 求解器与矩阵格式 | 预处理准备 (s) | 迭代求解 (s) | 总求解时间 (s) | 迭代步数 | 真实相对残差 | 相对 Ginkgo 加速比 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| **Ginkgo `1.11.0`**（标量 CSR ILU(0)） | `153.61` | `5.24` | `158.85` | `13` | `4.93e-3` | `1.00×` |
| **XianzhiKrylov `26.48`**（BSR3 块 ILU(0)） | `71.65`（分析 `0.35` + 分解 `71.30`） | `3.13` | **`74.77`** | `14` | `4.93e-3` | **`2.12×`** |

- 结构与块格式优势：`BSR3` 块存储与原生 `3×3` 块 `ILU(0)` 避免了标量 CSR 展开与标量级依赖开销，使预处理与迭代阶段耗时双双大幅低于同卡 Ginkgo 标量 CSR 路线，整体实现 **`2.12×`** 加速。
