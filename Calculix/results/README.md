# Result data

[English](README.md) | [简体中文](README.zh-CN.md) · [Home](../README.md)

| File | Dataset |
|---|---|
| [five-methods.json](five-methods.json) | Five-solver application benchmarks, including hardware, software versions, configurations, repeat statistics, and full-precision core times |
| [release-validation.json](release-validation.json) | One full-application validation run per refined model, including dimensions, residuals, native phase times, and complete-field comparisons |

The benchmark statistics and validation-run timings are separate datasets. For the timing definitions, repeat counts, and numerical checks, see [Results and validation](../docs/RESULTS.md).

Images under `figures/` show steady fields from CalculiX output. Per-case input parameters are available under `cases/<case>/parameters.json`.
