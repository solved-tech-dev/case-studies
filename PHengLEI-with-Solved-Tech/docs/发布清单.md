## 公开前确认

1. 让有权获取风雷的第三方能取得或从官方版本重建锁定的基线。当前 NAS03 的基线来自本地开发分支，尚未证实能从公开地址取得同一提交。公开前可由风雷团队提供可获取的基线，或将补丁移植到受支持的上游版本并重新验证。
2. 核对风雷补丁上下文、算例参数及网格转换产物的再分发授权。新增文件按权利方确认的条款补充许可和署名。
3. 公开仓库以 `PHengLEI-with-Solved-Tech/` 为应用目录。确认压缩网格下载和解包校验可用，正式发布后在文章中指向应用目录并记录对应提交。
4. 引用 20 步结果时注明 LinglongAMG 26.46、常驻 worker、五种配置、每组单次测量、压力后端计时范围和收敛记录。若要复现该表，还需提供 worker 的源码、启动配置和统计方法。若要报告进程内直接适配的性能，需用本包对应的路径另行测量。
