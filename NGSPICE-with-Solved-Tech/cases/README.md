# Circuit cases

These synthetic SPICE inputs represent five DC supply circuits with different wiring topologies. Each uses `.op` and saves all operating-point quantities. Generate an individual case or all five with [generate_cases.py](../tools/generate_cases.py). Grid dimensions, the exact input digests and expected assembled dimensions are in [manifest.json](manifest.json).

- **`pdn-interleaved-segments-dc`** divides a 1,120 × 900 grid into 32 × 30 node tiles. Each tile has a corner feed connected through 8 mΩ to 1.05 V. Only selected rows and columns have boundary connections. The spacing of vertical branches varies by tile column, and each grid node has a resistive load to ground.
- **`pdn-diagonal-straps-dc`** uses a 1,100 × 910 grid with horizontal wiring and vertical channels every four columns. It adds 0.18 Ω links between diagonally adjacent nodes and 0.12 Ω links spanning 17 horizontal grid intervals on every thirteenth row. A 1.00 V supply feeds the grid at 32-node intervals in both directions through 40 mΩ resistors. Loads are ground-referenced resistors.
- **`pdn-slotted-plane-dc`** partitions a 1,200 × 840 grid into 48-column by 36-row tiles, with a partial tile row at the edge. Slots interrupt the wiring between tiles, leaving only selected cross-boundary connections. Each tile receives a 1.05 V corner feed through 8 mΩ. Resistive loads connect the nodes to ground.
- **`pdn-dual-rail-resistive-dc`** uses two 1,000 × 500 grids for supply and return. At intersections spaced 12 grid intervals apart, 30 mΩ resistors connect the supply grid to 1.10 V and 25 mΩ resistors connect the return grid to ground. The two rails have different vertical branch spacings. A resistor and a fixed current sink in parallel load each pair of corresponding nodes. The load sees the voltage difference between the two rails.
- **`pdn-bus-straps-dc`** uses a 1,250 × 800 grid with nearest-neighbor connections along each row and vertical channels every four columns. Longer straps span 17 horizontal grid intervals on every thirteenth row. A 1.00 V supply connects through periodic feed resistors and ground-referenced load resistors draw current throughout the grid.

The matrix order is the assembled equation count, including source-related unknowns. The CSR count includes explicitly stored zeros. The capture and replay use full unsymmetrized sparse storage and the real general LU path.
