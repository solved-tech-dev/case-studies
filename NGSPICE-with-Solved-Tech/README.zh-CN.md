# NGSPICE-with-Solved-Tech

[English](README.md)

本包提供五种百万阶供电电路的 ngspice 直流工作点案例，采用实数双精度。通过生成器即可得到原测试使用的完整网表。

ngspice 根据网表组装方程，用原生 KLU 完成工作点计算。采集接口按顺序记录原始线性方程组，独立的 PanguLU 26.46 回放程序依次分析、分解并完成原来的三次求解。三次调用的矩阵结构和系数一致，因此后两次直接复用首次分解得到的数值因子。每次求解都核对原方程残差和完整 KLU 参考解。

| 电路 | 网格 | 矩阵阶数 | CSR 存储项 |
| --- | ---: | ---: | ---: |
| 交错分段馈电网 | 1,120 × 900 | 1,008,002 | 3,792,813 |
| 斜向联络母线 | 1,100 × 910 | 1,001,002 | 4,320,777 |
| 开槽电源平面 | 1,200 × 840 | 1,008,002 | 3,973,723 |
| 双电源轨 | 2 × (1,000 × 500) | 1,000,002 | 4,837,391 |
| 母线馈电网 | 1,250 × 800 | 1,000,002 | 3,653,469 |
